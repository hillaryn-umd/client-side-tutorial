# Hillary Nguyen — Client-side Tutorial

Three-page BMGT407 course website designed in Figma and exported with AutoHTML, then adapted for semantic HTML and responsive Bootstrap 5.3.8.

Figma: https://www.figma.com/design/FtobQPXZQfAo7S9vy3MbGg/

## Files
- index.html, about.html, contact.html: adapted AutoHTML exports
- css/styles.css, styles2.css, styles3.css: original generated CSS
- css/responsive.css: responsive layout, accessibility, and Bootstrap integration
- images/: original exported SVG assets

## Run
Open index.html, or use VS Code Live Server. No build step is needed. Bootstrap CSS and JavaScript load from jsDelivr.

## Deploy
GitHub Settings > Pages > Deploy from a branch > main > / (root).

The sample course details and contacts follow the assignment tutorial (Spring 2027). Contact links open an email draft; the site does not send messages itself.
